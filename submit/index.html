Contribute

Add something

The data is one JSON file in a public repo. There is no CMS, no login, and no approval queue beyond a pull request. Two ways in, depending on how comfortable you are with git.

Route one

Open a pull request

Add an object to data/resources.json, commit, open a PR. CI validates the schema, the twelve-word limit and duplicate links before anyone reviews it, so you'll know within a minute if something is off.

Edit the file on GitHub

Route two

File an issue

If you'd rather not touch JSON, the issue template asks the same questions in a form. Someone else turns it into an entry. Slower, but nothing gets lost.

Open the issue template

The bar

  • It solves a specific founder problem. Not "a good tool" — a tool for a moment. If you can't name the moment, it doesn't go in.
  • The description is honest and short. Twelve words, plain verbs, what it does for you. Never the tool's own homepage copy. CI counts the words and fails the build at thirteen.
  • If you haven't used it, say so. Set "verify": true and it renders with a muted unverified chip until someone confirms it. That's a normal state, not a failure — 49of 211 entries are sitting there right now.
  • No paid placement. There is no amount of money that buys a listing or a position. If a link ever carries an affiliate code it gets flagged on the card and declared in the repo. See About.

The shape of an entry

Required: name, what, stage, category, tags. Plus url, unless verify is true. Everything else is optional.

{
  "name": "SeedLegals",
  "url": "https://seedlegals.com/",
  "what": "UK funding rounds and SEIS/EIS paperwork",
  "stage": "legal",
  "category": "Cap table",
  "tags": ["uk", "paid"],

  "verify": false,
  "why": "Optional. One or two sentences of first-hand context.",
  "alternatives": ["Vestd"],
  "addedBy": "your-github-handle",
  "lastChecked": "2026-08-06"
}

stage is one of: explore, validate, build, brand, launch, grow, fund, legal, team, operate, learn, exit.

tags come from a fixed list of 30: free, freemium, paid, uk, us, india, asia, europe, canada, global, grant, non-dilutive, program, community, directory, ai, no-code, open-source, seo, reading, template, agency, b2b, ecommerce, enterprise, research, data, pr, affiliate, mobile. Adding a new one means changing data/schema.json in the same pull request, and being able to explain why the existing ones don't do the job.
