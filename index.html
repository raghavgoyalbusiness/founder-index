What this is

Most directories file things by software category, which only works if you already have the vocabulary for your problem. You don't know you need attribution software. You know you launched and nobody is coming back. So this is filed by the question instead, and the answer is two or three things rather than forty.

It started as a messy running list of links — the kind you accumulate over years of building things, half of it saved at 2am and never opened again. Every entry was used or researched by someone building a real company. That's the whole credibility claim. It is a working notebook, opened up.

There is no paid placement and there never will be. The data is a JSON file in a public repo, so if something is wrong you can fix it yourself, and if a tool wants in it has to earn it the same way as everything else. 49 of the 211 entries carry an unverified chip, which means nobody has confirmed the link or the description yet — those are the best place to start if you want to help.
